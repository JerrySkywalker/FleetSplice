# Research

FleetSplice is currently research-first and implementation-blocked.

Start with [`research-program-0.1.md`](research-program-0.1.md), then use [`upstream-study-matrix.md`](upstream-study-matrix.md) and [`open-questions.md`](open-questions.md) to organize evidence.

Research outputs must distinguish verified facts, interpretations, recommendations, and unresolved questions. Upstream behavior, protocol support, licenses, and versions should be checked against current authoritative sources rather than assumed from prior discussion.

- [Codex CLI and ChatGPT desktop completion extension audit, 2026-10-31](client-completion-extension-audit-2026-10-31.md) — standard MCP completion, native composer mentions, input adapters, and FS-owned editor boundaries; documentation/source verification, not an end-to-end plugin acceptance.

# R03 — G08 long-history failure modes and route cost

This is a design comparison, **not** an FS or Paseo 10k-item benchmark. Let `N` be projected items, `B` retained content bytes, `H` active Hosts, `S` sessions, and `K` a fetched page. A page of `K` rows bounds a response only if the upstream store, scan, client state and per-row bytes have their own bounds. Product correctness also requires every older item remain addressable by stable ID and any clipped large output have an honest source/retrieval path.

## Route-level G08 judgement

- **A** has a usable paged client fetch, partial output clipping and epoch recovery. It fails the strict **bounded daemon residency** and complete large-output requirement by current source. Existing incidents are versioned reports; no claim is made that every session crashes.
- **B2** can stream its own small event representation, but Paseo still stores the projected Agent timeline and the standard app keeps its own history. A separate plugin screen that discards old rows changes product behavior and cannot alone satisfy complete retrieval. **B3** could fix the core, but the necessary server, app cache/DOM, byte planner and migration changes are a substantial upstream program. **B4** pays continuous merge cost.
- **C** has an accepted [Hub/Edge SQLite + content-addressed blob and hot/warm/cold architecture](../../../architecture/history-and-handoff.md). The current [native adapter](../../../../packages/native-adoption/adapter.ts) reads at most 12 turns and projects at most 48 messages with `historyLimited`; this provides bounded *current view*, not complete older history. G08 must implement durable pages, indexes, byte-aware blobs, cursor repair, client eviction and historical correctness before it can claim a win.

There are **no same-scenario CPU, RSS, heap, first-tail paint or 10k-item comparison numbers** in this study. FS Gate P's local discovery improvement (74→18 RPC) is not cross-product history performance. Synthetic source complexity supports a risk classification, not a speed ranking.

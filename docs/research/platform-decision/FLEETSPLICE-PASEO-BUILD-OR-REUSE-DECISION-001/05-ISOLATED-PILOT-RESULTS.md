## Evidence and limits

The artifact scratch folder contains only a pinned shallow Paseo **source** checkout and selected public Codex source files; neither was built or executed. The study's current-version facts are `codex-cli 0.162.1`, Paseo released `v0.11.2`, and pinned Git SHAs in [SOURCE-REGISTER.md](SOURCE-REGISTER.md). Historical FS acceptance has named hosts and fixtures; it is not a new R04 measurement. Mobile status is `MOBILE_UX_UNVERIFIED`. No performance value or CPU/RAM winner is asserted.

The one unresolved native question requires a separate Owner-admitted, authenticated **unwrapped ZenBook14 TUI** observation: preserve its PID/creation time and thread ID, confirm an official shareable app-server PID/endpoint and Writer owner, then attach a second *connection* and observe a harmless exact native response plus return to that same TUI. Do not use this research sandbox to borrow daily credentials or start a live Owner session.
